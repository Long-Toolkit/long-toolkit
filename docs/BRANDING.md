# Branding

`Long-Toolkit` is a free and open-source project that values consistency in both its visual identity and its user experience, across the documentation, the README files and the command-line interface (CLI). This page gathers the resources that define that identity.

## Colours

The accent colour of `Long-Toolkit` is the pink `#dea2c2`, used on dark backgrounds, with the deeper `#b0567f` for text links on the light background (`#fff6eb`), where the lighter pink would not be readable.
